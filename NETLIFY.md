# Publicar en Netlify Drop

1. Abre https://app.netlify.com/drop
2. Arrastra el archivo `crianza-netlify.zip` (está en esta carpeta) o toda la carpeta del proyecto
3. Espera la URL (ej. `https://algo-random.netlify.app`)
4. Guarda ese link

Cuando configures Firebase Auth, añade ese dominio en:
Authentication → Settings → Authorized domains
